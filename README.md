## Summary

An end-to-end governed data + AI product built on Databricks Free Edition, starting from three CSV files of oil & gas production data. The project stands up a star schema in Unity Catalog, adds AI-assisted metadata, exposes the data through a Genie Space and an AI/BI dashboard, trains and registers a production forecasting model, and serves history + forecast through a lightweight Databricks App.

## Architecture

Raw CSVs → Lakeflow Declarative Pipeline → Unity Catalog (star schema) → Genie Space / AI-BI Dashboard / ML model → Databricks App

**Star schema** (`istm637_jfernandezcanela.oilgas`):
- `dim_well` — ~50 wells (location, completion, status)
- `dim_date` — ~547 days (Jan 2024–Jun 2025)
- `fact_production` — ~22,800 rows, grain = well × day
- `well_forecast` — 180-day oil rate forecast per producing well, generated by the
  registered model

## How to Reproduce

1. **GitHub + Databricks**: link a GitHub account under Settings → Linked accounts,
   create a Git folder in Databricks pointing at this repo.
2. **Setup**: open the starter notebook, set `NETID`, run the setup cells to create
   the catalog/schema/volume.
3. **Ingest**: upload the three provided CSVs to the `raw` volume, then run the
   Lakeflow pipeline (`ISTM637_Lakeflow_Ingest_Pipeline.sql`) to materialize the
   three star-schema tables.
4. **Metadata**: in Catalog Explorer, use AI-generate on each table, review/correct
   suggestions, and apply governance tags (`domain`, `layer`, `pii`).
5. **Genie Space**: create a space over the three tables; instructions and trusted
   queries are documented in the project report.
6. **Dashboard**: build the AI/BI dashboard (Data Model with `well_id`/`date_id`
   relationships, 5 visualizations, a basin filter).
7. **Model**: run the predictive model notebook top to bottom — trains a
   gradient-boosted regressor (R² ≈ 0.93), registers `oil_rate_predictor` in
   Unity Catalog with the `@champion` alias, and writes `well_forecast`.
8. **App**: deploy the `oil-well-production-app` Databricks App (Streamlit),
   which reads `fact_production`/`dim_date` for history and `well_forecast`
   for the forecast, for a well selected from `dim_well`.
